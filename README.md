# Paradise Nursery Shopping Cart (`e-plantShopping`)

This is my first React project! It is an online plant shop application for **Paradise Nursery** where users can explore a variety of house plants, add items to their shopping cart, manage quantities, and proceed to checkout.

## Features
- **Landing Page:** Features a welcoming introduction and a button to explore products.
- **Navigation Bar:** Includes links to the landing page, product listing, and a shopping cart icon with a live item counter.
- **Product Catalog:** Showcases house plants categorized into sections (e.g., Aromatic Plants, Medicinal Plants) with descriptions, images, costs, and an "Add to Cart" button.
- **Interactive Shopping Cart:** Displays items in the cart with thumbnails, unit costs, total costs per item, and buttons to increase, decrease, or delete items.

## Technologies Used
- React (Components, Hooks: `useState`, `useEffect`)
- Redux (State management for the shopping cart)
- CSS for styling
